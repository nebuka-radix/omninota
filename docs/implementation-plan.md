## テスト方針

Unit:
- GTD業務ルール
- 入力検証
- 日付と日時の扱い

Integration:
- RepositoryのCRUD
- マイグレーション
- トランザクション
- バックアップ・復元
- IPC契約

E2E:
- 起動
- タスク追加・編集・完了
- 画面遷移
- 再起動後の復元
- ペイン・タブ状態
- パッケージ化後の保存

Unit・Integrationはvitest（ホストNode.js、`npm test`）で実行する。
